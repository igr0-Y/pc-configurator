# PC Configurator

🔗 **Живая демонстрация:** http://195.133.67.40:8000/

Backend для конфигуратора ПК с проверкой совместимости компонентов. Пользователь собирает сборку из процессора, материнской платы, видеокарты, БП, охлаждения, корпуса, RAM и накопителей — система в реальном времени проверяет совместимость и выдаёт вердикт по сборке.

Фронтенд (HTML/JS) сгенерирован с помощью AI для демонстрации работы API — вся бизнес-логика и backend написаны самостоятельно.

## Стек

- **Python 3** / **FastAPI**
- **PostgreSQL** + **SQLAlchemy** (ORM)
- **Pydantic** — валидация данных

## Функционал

- CRUD для сборок (создание, изменение, удаление)
- Каталог компонентов с фильтрацией (сокет, ядра/потоки, наличие встроенной графики и др.)
- Проверка совместимости:
  - сокет CPU ↔ материнская плата
  - сокет CPU ↔ кулер (через отдельную таблицу поддерживаемых сокетов)
  - охлаждение процессора (TDP кулера vs. потребление CPU)
  - длина видеокарты ↔ максимально допустимая длина в корпусе
  - форм-фактор материнской платы ↔ корпус
  - тип и объём RAM ↔ поддержка материнской платой
  - количество слотов RAM / накопителей
  - рекомендуемая мощность БП
  - баланс производительности CPU/GPU (по бенчмаркам)
- Динамическая генерация текстового вердикта по собранной конфигурации
- Работа с несколькими модулями RAM и накопителями в одной сборке (таблицы-связки)

## Структура проекта

```
main.py                     — эндпоинты FastAPI
models.py                   — модели SQLAlchemy (компоненты, сборки, связи)
schemas.py                  — Pydantic-схемы для входных данных
database.py                 — подключение к БД
compatibility.py            — логика проверки совместимости и генерации вердикта
static/icons/               — иконки компонентов
pcconfigurator_html.html    — демо-фронтенд (AI-generated)
```

## Запуск

1. Установить зависимости:
```bash
pip install fastapi uvicorn sqlalchemy psycopg2-binary python-dotenv
```

2. Создать файл `.env` на основе `.env.example` и указать свою строку подключения к PostgreSQL.

3. Запустить сервер:
```bash
uvicorn main:app --reload
```

4. Открыть `pcconfigurator_html.html` в браузере (фронтенд обращается к `http://127.0.0.1:8000`).
